# Better implementations

This project's current implementation is one way of pursuing its goals, not a permanent restriction. Use a better method when it delivers a better result, whether it replaces one component or the whole approach. Preserve the purpose and useful capabilities, evaluate results, and document newly developed methods with their own dates.
